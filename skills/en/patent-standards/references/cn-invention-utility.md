# Invention / Utility Model — Verified Anchors (发明/实用新型 — 核实锚点)

> Consumers: patent-application (invention / utility-model branch), patent-claims, patent-specification, patent-drawings (drawings part), patent-compliance (checks 1-7), patent-filing (invention / utility-model parts). Design anchors in `cn-design.md`.
> Verification: 2026-08-11 tested against the official CNIPA full texts (2023 实施细则 full text + 2020 专利法 text); **cite article numbers, never number from memory**.

## 专利法 (2020 text; the 2023 revision did not change article numbers; source: cnipa.gov.cn full text + flk.npc.gov.cn)

| Article | Gist (drafting-relevant) |
|---|---|
| 第2条 | invention = new technical solution for a product, a method, or an improvement thereof; utility model = new technical solution for the shape, construction, or combination thereof of a product |
| 第9条 | only one patent may be granted for the same invention-creation; same-day invention + utility model can be dual-filed (abandon the utility model later) |
| 第22条 | novelty / inventive step / practical applicability; invention = prominent substantive features and notable progress, utility model = substantive features and progress; prior art = technology made available to the public before the filing date, at home or abroad |
| 第24条 | four situations within 6 months before the filing date do not lose novelty (state of emergency / public interest, international exhibition, academic meeting, disclosure by others) — applies to designs too, see cn-design.md |
| 第26条 | application documents = request, specification with abstract, and claims; the specification shall be clear and complete, enabling a person skilled in the art to carry it out; claims shall be supported by the description and define the protection scope clearly and concisely |
| 第33条 | amendments must not go beyond the scope recorded in the original specification and claims (designs limited to the original pictures / photos, see cn-design.md) |
| 第42条 | invention 20 years / utility model 10 years, from the filing date (design 15 years, see cn-design.md) |

## 专利法实施细则 (2023 revision, 国务院令第769号, 13 chapters, 149 articles; source: cnipa.gov.cn full text)

| Article | Gist (drafting-relevant) |
|---|---|
| 第17条 | application documents shall meet the prescribed requirements; a power of attorney is required when a patent agency is entrusted |
| 第20条 | five-part specification: technical field / background art / summary of invention / brief description of drawings / detailed description; title consistent with the request; no "as described in the claims" cross-references and no commercial marketing language; **utility-model specifications must include drawings showing the product's shape / construction / combination** |
| 第21条 | figures numbered in order "图1, 图2 …"; reference-numeral consistency (numerals not mentioned in the text must not appear in the figures, and vice versa; the same part carries the same numeral); no annotations beyond essential words |
| 第22条 | claims record technical features; Arabic-numeral numbering; scientific / technical terms consistent with the specification; unless absolutely necessary, no "如说明书…所述" / "如图…所示"; reference numerals may be cited but must be in parentheses, not construed as limitations |
| 第23条 | shall have an independent claim; the independent claim reflects the technical solution as a whole and records the essential technical features for solving the technical problem; dependent claims further limit via additional technical features |
| 第24条 | independent claim = preamble (subject name + essential features shared with the closest prior art) + characterizing portion ("其特征是…" distinguishing features); one application has only one independent claim, placed before the dependent claims |
| 第25条 | dependent claim = citation part (number + subject name) + limiting part (additional features); may only cite an earlier claim; a multiple dependent claim may only cite one alternative and must not serve as the basis of another multiple dependent claim |
| 第26条 | abstract: name + technical field + problem + solution gist + main uses; when there are drawings, designate one in the request as the abstract figure; no commercial marketing language (**note: the 2023 version removed the old "abstract ≤300 characters" limit**) |
| 第43条 | filing date: on receipt of the request, the specification (utility models must include drawings) and the claims (design scope in cn-design.md) |
| 第46条 | drawings described in the specification but not submitted / missing: late-submitted drawings take the submission date as the filing date — **missing drawings can lose the filing date; extremely risky** |
| 第47条 | same-day filing: the same applicant filing both utility model and invention for the same invention-creation on the same day shall declare so separately at filing |
