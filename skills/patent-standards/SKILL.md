# Patent Standards (专利标准/资料目录)

The catalog of authoritative texts governing patent drafting and examination in CN and US, plus the citation discipline every writing skill follows. This skill is a **declaration**, not a retrieval tool: it says what exists and where; the environment's tools do the actual reading.

## Verified rule anchors (2026-08-11 / 2026-08-12 实测核实)

Drafting-relevant article numbers verified against the official full texts (来源见下): the 2023 实施细则 from CNIPA (全文) and 专利法 2020 text from CNIPA. **Skills must cite these anchors — not chapter-level approximations — and never renumber from memory.** 外观设计锚点 2026-08-12 补核,证据见 `../../docs/research/design-patent-anchors.md`。

### 专利法(2020 文本,2023 修订未改条号;来源: cnipa.gov.cn 全文 + flk.npc.gov.cn)

| 条文 | 要旨(撰写相关) |
|---|---|
| 第2条 | 发明=产品/方法/其改进的新技术方案;实用新型=产品的形状、构造或其结合的新技术方案;**外观设计(第4款)=对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计** |
| 第9条 | 同样的发明创造只能授予一项专利权;同日申请发明+实用新型可一案两请(后放弃实用新型) |
| 第22条 | 新颖性/创造性/实用性;发明=突出的实质性特点和显著的进步,实用新型=实质性特点和进步;现有技术=申请日前国内外为公众所知的技术 |
| 第23条 | 外观设计授权条件:不属于现有设计;与现有设计或其组合相比具有明显区别;不与他人在先合法权利冲突(现有设计 = 申请日前国内外为公众所知的设计) |
| 第24条 | 申请日前6个月内的四种情形不丧失新颖性(紧急状态公共利益/国际展/学术会议/他人泄露) |
| 第26条 | 申请文件=请求书、说明书及其摘要和权利要求书;说明书应清楚完整、以本领域技术人员能够实现为准;权利要求书应以说明书为依据,清楚、简要地限定保护范围 |
| 第27条 | 外观设计申请文件:请求书 + 图片或者照片 + 简要说明;图片或照片应清楚显示要求专利保护的产品的外观设计 |
| 第31条第2款 | 外观设计单一性:一件申请限一项外观设计;同一产品两项以上相似外观设计、同一类别且成套出售或使用的产品的两项以上外观设计,可作为一件申请 |
| 第33条 | 修改不得超出记载范围:发明/实用新型 = 原说明书和权利要求书记载的范围;外观设计(第2款)= 原图片或者照片表示的范围 |
| 第42条 | 发明20年/实用新型10年/外观15年,自申请日起算 |

### 专利法实施细则(2023年修订,国务院令第769号,13章149条;来源: cnipa.gov.cn 全文)

| 条文 | 要旨(撰写相关) |
|---|---|
| 第17条 | 申请文件应当符合规定的要求;委托代理机构应提交委托书 |
| 第20条 | 说明书五段式:技术领域/背景技术/发明内容/附图说明/具体实施方式;名称与请求书一致;不得用"如权利要求…所述"引用语与商业性宣传用语;**实用新型说明书必须有表示产品形状/构造/结合的附图** |
| 第21条 | 附图按"图1,图2…"顺序编号;附图标记一致性(文字未提及的标记不得出现在附图中,反之亦然;同一组成部分标记一致);附图除必需词语外不含其他注释 |
| 第22条 | 权利要求书记载技术特征;阿拉伯数字编号;科技术语与说明书一致;除绝对必要外不得用"如说明书…所述"/"如图…所示";附图标记可引用但须置于括号内,不得解释为限制 |
| 第23条 | 应有独立权利要求;独权从整体上反映技术方案、记载解决技术问题的必要技术特征;从权用附加技术特征进一步限定 |
| 第24条 | 独权=前序部分(主题名称+与最接近现有技术共有的必要技术特征)+特征部分("其特征是…"区别特征);一项发明/实用新型只有一个独权,写在从权之前 |
| 第25条 | 从权=引用部分(编号+主题名称)+限定部分(附加特征);只能引用在前的权利要求;多项从权只能择一引用,不得作为另一项多项从权的基础 |
| 第26条 | 摘要:名称+技术领域+问题+方案要点+主要用途;有附图时应在请求书中指定一幅作摘要附图;不得使用商业性宣传用语(**注意:2023版已删除旧版"摘要不超过300字"的限制**) |
| 第30条 | 外观设计图片或者照片:就每件产品所需保护的内容提交;局部外观设计提交整体产品视图并用虚线与实线表明保护部分;请求保护色彩应提交彩色图片或照片 |
| 第31条 | 外观设计简要说明:名称、用途、设计要点,并指定一幅最能表明设计要点的图片或照片;省略视图或请求保护色彩应写明;相似设计应指定基本设计;不得使用商业性宣传用语、不得说明产品的性能 |
| 第32条 | 样品或模型:必要时可要求提交;体积≤30cm×30cm×30cm、重量≤15kg |
| 第40条 | 相似外观设计(≤10项,与基本设计相似)/ 成套产品(同一大类、习惯上同时出售或使用、相同设计构思);多项外观设计应顺序编号标注在图片或照片名称前 |
| 第43条 | 确定申请日:发明/实用新型 = 收到请求书、说明书(实用新型必须包括附图)和权利要求书;外观设计 = 收到请求书、图片或者照片和简要说明 |
| 第44条 | 不予受理:外观设计申请缺少请求书、图片或者照片、简要说明 |
| 第46条 | 写有附图说明但无附图/缺附图:补交附图的以补交之日为申请日——**遗漏附图会丢失申请日,风险极高** |
| 第47条 | 同日申请:同一申请人同日对同样的发明创造既申请实用新型又申请发明,应在申请时分别说明 |
| 第57条第2款 | 外观设计申请人自申请日起2个月内可主动修改 |
| 第58条第2款 | 外观设计图片或者照片的修改,应当按规定提交替换页 |

## How writing skills invoke this skill

Two consumption modes (ADR-0004):

- **自服务组(`skills/self-service/`)**:直接引用上方 **Verified rule anchors** 的条号作为锚点(如 `细则第20条`),需要向发明人解释时说明来源。不声明 `[STANDARD]` 需求、不强求环境检索法条;现有技术按诚实红线(三类素材)处理,见 `../../docs/prototype/delegation-contract.md` 的"自服务组简化变体"节。
- **专业组(`skills/professional/`,US 技能,当前隐藏)**:按下方完整纪律(declare/consume/cite)执行。

## The discipline — four clauses, one prohibition (专业组完整版)

Writing skills apply the delegation contract (`../../docs/prototype/delegation-contract.md`) when they consume this catalog:

1. **Declare** — before a legal assertion, name the need: `[STANDARD] <jurisdiction> <topic>`. Look up the governing material + anchor in this catalog, then have the environment read that material. Never fetch it yourself.
2. **Consume** — ground only on what was actually read.
3. **Cite** — every assertion in output carries the anchor: `(依据: 指南 第二部分第四章[创造性] — cnipa.gov.cn)` / `(per MPEP §2106 — uspto.gov)`.
4. **Fail loud** — if the material can't be read, emit the 无法获取依据 block and don't draft that portion.
5. **Never invent** — never restate law from memory; the catalog's material is the only authority.

## 自服务组纪律(简化版)

自服务技能引用本目录时遵守:

1. **锚点**:引用 Verified rule anchors 的条号(实测核实),不凭记忆编号。
2. **诚实红线**:现有技术只写三类素材 — 发明人已知方案 / 客观通用问题 / 检索工具真实返回。绝不编造专利号、文献、实验数据。
3. **Fail loud**:缺输入(如四要素不齐)、缺工具(如无 dot)时明说缺什么,不硬写。
4. **范围外**:OA 答复等专业工作不在本包。
