# 外观设计 — 核实锚点

> 消费方:patent-application(外观设计分支)、patent-drawings(外观附图节)、patent-compliance(检查项8)、patent-filing(外观电子申请要点)。发明/实用新型锚点见 `cn-invention-utility.md`。
> 核实:2026-08-12 对 CNIPA 官方全文实测(专利法 2020 文本 + 2023 实施细则全文 + 审查指南 2023 PDF 全文),逐条证据见 `../../../docs/research/design-patent-anchors.md`。**2023 版细则/指南无固定六视图强制、无"3cm×3cm/15cm×22cm"图片尺寸数值(2010 旧规则已删);视图按设计要点涉及的面数定。**

## 专利法(2020 文本;来源: cnipa.gov.cn 全文)

| 条文 | 要旨(撰写相关) |
|---|---|
| 第2条第4款 | 外观设计定义:对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计 |
| 第23条 | 授权条件:不属于现有设计;与现有设计或其组合相比具有明显区别;不与他人在先合法权利冲突(现有设计 = 申请日前国内外为公众所知的设计) |
| 第24条 | 宽限期(申请日前6个月内四种情形不丧失新颖性)——同发明/实用新型,见 cn-invention-utility.md |
| 第27条 | 申请文件:请求书 + 图片或者照片 + 简要说明;图片或照片应清楚显示要求专利保护的产品的外观设计 |
| 第31条第2款 | 单一性:一件申请限一项外观设计;同一产品两项以上相似外观设计、同一类别且成套出售或使用的产品的两项以上外观设计,可作为一件申请 |
| 第33条第2款 | 修改不得超出原图片或者照片表示的范围 |
| 第42条 | 外观设计保护期 15 年,自申请日起算 |

## 专利法实施细则(2023年修订,国务院令第769号;来源: cnipa.gov.cn 全文)

| 条文 | 要旨(撰写相关) |
|---|---|
| 第30条 | 图片或者照片:就每件产品所需保护的内容提交;局部外观设计提交整体产品视图并用虚线与实线表明保护部分;请求保护色彩应提交彩色图片或照片 |
| 第31条 | 简要说明:名称、用途、设计要点,并指定一幅最能表明设计要点的图片或照片;省略视图或请求保护色彩应写明;相似设计应指定基本设计;不得使用商业性宣传用语、不得说明产品的性能 |
| 第32条 | 样品或模型:必要时可要求提交;体积≤30cm×30cm×30cm、重量≤15kg |
| 第40条 | 相似外观设计(≤10项,与基本设计相似)/ 成套产品(同一大类、习惯上同时出售或使用、相同设计构思);多项外观设计应顺序编号标注在图片或照片名称前 |
| 第43条 | 确定申请日:收到请求书、图片或者照片和简要说明(发明/实用新型口径见 cn-invention-utility.md) |
| 第44条 | 不予受理:申请缺少请求书、图片或者照片、简要说明 |
| 第53条 | 写明产品所属类别的,应使用国务院专利行政部门公布的外观设计产品分类表 |
| 第57条第2款 | 自申请日起2个月内可主动修改 |
| 第58条第2款 | 图片或者照片的修改,应当按规定提交替换页 |

## 审查指南(2023 版,局令第78号)章节锚点(外观设计初步审查;经 PDF 全文目录核实)

| 锚点 | 主题 |
|---|---|
| 第一部分第三章 4.2 | 外观设计图片或者照片(视图按设计要点涉及的面数:涉及六面才需六面正投影视图;只涉及一面或几面提交所涉及面视图、其他面可补立体图;省略视图须在简要说明写明原因) |
| 第一部分第三章 4.2.1 | 视图名称及其标注(主/后/左/右/俯/仰视图,标注在视图正下方;套件N/设计N/组件N 编号) |
| 第一部分第三章 4.2.2 | 图片的绘制(粗细均匀实线表达形状;不得用阴影线/指示线/中心线/尺寸线/点划线;计算机绘制分辨率满足清晰要求) |
| 第一部分第三章 4.2.3 | 照片的拍摄(清晰、单一背景、正投影规则、避免强光反光阴影倒影、避免内装物衬托物) |
| 第一部分第三章 4.2.4 | 图片或者照片的缺陷(视图投影关系错误、不清晰或图形尺寸过小、应删除线条、六面显示不全、对称面省略规则等) |
| 第一部分第三章 4.3 | 简要说明(名称与请求书一致、用途、设计要点、指定一幅最能表明设计要点的图片;请求保护色彩/省略视图应写明;禁商业性宣传用语与性能说明) |
| 第一部分第三章 4.4 | 局部外观设计(提交整体产品视图,虚线/实线表明保护部分) |
| 第一部分第三章 4.5 | 涉及图形用户界面的产品外观设计(整体/局部两种提交方式) |
