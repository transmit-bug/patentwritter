## 专利法 (2020 text, 82 articles; the 2023 revision did not change article numbers; source: cnipa.gov.cn full text)

| Article | Gist (prosecution-relevant) |
|---|---|
| 第20条 | honesty / good-faith principle (added 2020): prosecuting and exercising patent rights shall follow the principle of good faith — the professional discipline's honesty red line at the agent level |
| 第22条 | novelty (22.2) / inventive step (22.3) / practical applicability (22.4); prior art definition — the substantive grounds behind OA and invalidation |
| 第26条 | 26.3 sufficient disclosure; 26.4 claims supported by the description, clear and concise — clarity / support rejections |
| 第29条 | priority windows: foreign priority — invention / utility model within 12 months of the first foreign filing, design within 6 months; domestic priority — invention / utility model 12 months, design 6 months, same subject filed in China |
| 第30条 | claiming priority: written declaration at filing + copy of the first application within 16 months (invention / utility model) or 3 months (design); missing declaration / copy → 视为未要求优先权 |
| 第33条 | amendments must not go beyond the original specification and claims — the red line for every OA / re-exam / invalidation amendment |
| 第35条 | request for substantive examination within 3 years from the filing date (invention) |
| 第37条 | after substantive examination, notify the applicant to state opinions or amend; failure to respond within the specified period → deemed withdrawn — the OA trigger |
| 第38条 | where the application still does not comply after opinions / amendment, it shall be rejected |
| 第41条 | re-exam request within 3 months of the rejection decision (41.1); suit against the re-exam decision within 3 months (41.2) |
| 第45条 | from the grant announcement, any entity or individual may request invalidation — invalidation trigger |
| 第46条 | CNIPA examines the invalidation request, makes a decision, registers and announces it (46.1); suit within 3 months, the other party joins as third party (46.2) |
| 第47条 | an invalidated patent is deemed never to have existed; no retroactive effect; bad-faith damages exception |
| 第50条第2款 | open-license declaration for utility models / designs must be accompanied by a patent evaluation report |
| 第66条第2款 | in infringement disputes, the court / patent administrative department may require a patent evaluation report — its evidentiary role |

## 专利法实施细则 (2023 revision, 国务院令第769号, 13 chapters, 149 articles; source: cnipa.gov.cn full text)

| Article | Gist (prosecution-relevant) |
|---|---|
| 第57条 | 1: invention voluntary amendment within 3 months of the substantive-examination request / entry notice; 2: utility model / design voluntary amendment within 2 months of filing; **3: after an OA notice, amendments shall be directed to the defects pointed out in the notice**; 4: ex-officio correction of obvious errors |
| 第48条 | division (分案): an application covering two or more inventions / utility models / designs may be divided before the 细则第60条第1款 deadline; not possible once rejected / withdrawn / deemed withdrawn; 分案不得改变原申请类别 |
| 第49条 | division retains the original filing date (and priority date if claimed), must not exceed the original disclosure; the request states the original application number and filing date |
| 第58条 | amended parts submitted as replacement pages (designs: pictures / photos likewise) |
| 第59条 | the cases in which rejection under 法38 applies — rejection-basis checklist |
| 第62条 | evaluation-report requester: patentee, interested party, **and (2023 addition) the accused infringer**; subject matter; request form |
| 第63条 | evaluation report made within 2 months of the request; only one report per patent right; any entity or individual may inspect / copy |
| 第65条 | re-exam request form + grounds + evidence; cases not accepted / deemed not filed (per 法41) |
| 第66条 | during re-exam, amendments limited to removing defects pointed out in the rejection decision or the re-exam notice |
| 第67条 | re-exam decision: uphold the rejection / revoke the rejection and continue examination |
| 第68条 | the re-exam request may be withdrawn before the decision |
| 第69条 | invalidation request + evidence in duplicate (1); **2: closed list of invalidation grounds** (法2 / 19.1 / 22 / 23 / 26.3 / 26.4 / 27.2 / 33, 细则11 / 23.2 / 49.1, 法5 / 25, 法9 double-patenting) — grounds outside the list are inadmissible |
| 第70条 | not-accepted cases (insufficient grounds / evidence, same grounds + evidence re-request, design prior-right conflict evidence) |
| 第71条 | grounds may be added / evidence supplemented within 1 month of the request — evidence-deadline discipline |
| 第72条 | transfer notice; patentee states opinions |
| 第73条 | during invalidation, claim amendments must not broaden the protection scope; invention / utility-model specs and drawings may not be amended; designs: pictures / photos / brief explanation may not be amended |
| 第74条 | oral hearing (notice, consequences of absence) — oral-hearing discipline |
| 第76条 | the invalidation request may be withdrawn before the decision |
| 第110条 | fees: substantive-examination fee, re-exam fee, evaluation-report request fee, invalidation request fee |

## 审查指南 (2023 edition, 局令第78号, effective 2024-01-20; source: CNIPA PDF full text, chapter-section verified)

| Anchor | Topic |
|---|---|
| 第二部分第二章 3.2.1 / 3.2.2 / 3.2.3 | claims supported by the description / clear / concise (all under 法26.4) |
| 第二部分第三章 3.1 | novelty examination principle (2): **single-reference comparison** |
| 第二部分第四章 3.2.1.1 | inventive-step examination method — **three-step method**: (1) closest prior art → (2) distinguishing features and the actually-solved technical problem → (3) whether the invention is obvious to a person skilled in the art (technical teaching) — rebuild creative argumentation from this anchor, not from case-library templates |
| 第二部分第七章 | search (检索): the delegated-search discipline's position in prosecution (撰写前检索、OA 补充检索、无效证据检索、评价报告检索) |
| 第二部分第八章 4.10.3 | first OA response period: **4 months** — a specified period, extendable on request; "以通知书指定期限为准", never hard-code |
| 第二部分第八章 4.11.3.2 | subsequent OA response period: **2 months** — same specified-period caveat |
| 第二部分第八章 4.12 / 4.13 | interview / telephone discussion and other means |
| 第二部分第八章 5.1.1 | response by opinion statement or correction document within the specified period (per 法37) |
| 第二部分第八章 5.2 | amendment (per 法33; 细则57.1 voluntary-amendment timing, 细则57.3 response amendments; 5.2.2 allowed, 5.2.3 not allowed) |
| 第四部分 | **复审与无效请求的审查** (2023 renamed from "复审与无效宣告程序"; 8 chapters: general rules / re-exam request examination incl. 前置审查 3 / invalidation request examination incl. amendment 4.6 / oral hearing / design & utility-model invalidation chapters / same-invention handling / evidence) |
| 第五部分第十章 | 专利权评价报告 (request formalities → evaluation 3.2 content / 3.3 search → report content / sending / inspection-copy / correction) — the evaluation report is not an administrative decision and is not appealable |

## 摘要 300 字 — 三处文本不一致 (annotate in outputs, 按细则为准)

细则 2023 第26条已删去摘要字数限制（2010 版有 300 字限制）;但**审查指南 2023 第一部分第一章 4.5.1 仍要求「摘要文字部分（包括标点符号）不得超过 300 个字」**,2025 考试大纲同样按 300 字表述。实务以指南的初步审查要求为准（超 300 字会被通知删节或依职权删节）。技能输出涉及摘要时标注此不一致,并说明按细则为准、指南仍在执行。

## 执业边界与诚实 (agent-side anchors)

| Anchor | Gist |
|---|---|
| 专利法第18条 | foreign applicants must entrust a Chinese patent agency; CN entities / individuals may entrust; agency confidentiality duty |
| 专利法第20条 | good-faith principle (see above) |
| 专利代理条例第13条 | agency business scope: applications, invalidation, assignment, licensing contracts, consultation |
| 专利代理条例第16条 | agent acts on the agency's assignment, must not accept engagements directly |
| 专利代理管理办法第8条 | no entity / individual may act as agent without approval |
| 专利代理管理办法第25条 | agent shall be assigned by the agency, must not accept engagements directly |
| 专利代理管理办法第35条 | annual-report business types: applications / invalidation / transfer / licensing / administrative handling and litigation of disputes / pledge financing |
| 《规范申请专利行为的规定》(局令第77号) | abnormal-application definition and handling — agencies involved may be listed as seriously dishonest and lose their license; the package's honesty red line at the agent level |
