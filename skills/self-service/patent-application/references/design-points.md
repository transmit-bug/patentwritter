# 外观设计申请要点(外观访谈组 + 撰写要点)

外观设计保护的是**产品的外观本身**(形状、图案、色彩及其结合,富有美感并适于工业应用),不是技术方案。因此发明/实用新型的**"四要素"(技术问题/技术方案/区别特征/技术效果)不适用**——外观设计改走:**类别 + 设计要点**。规则依据见 patent-standards 的 `references/cn-design.md`(专利法第2条第4款/第23条/第27条/第31条第2款/第33条第2款;细则第30/31/40条;指南 第一部分第三章 4.2-4.5)。

## 外观访谈组(阶段1 交底访谈用,替代四要素提问)

按顺序问,覆盖了就跳,每组 AskUserQuestion ≤4问:

1. 这是什么产品?产品叫什么?(→ 产品名称,决定类别)
2. 这个产品主要是"造型/图案好看"在卖,还是"功能结构"在卖?(→ 判断是否真外观设计;功能结构改进 → 回 type-decision 走发明/实用新型)
3. 相比市面上的产品,你的外观**区别点**在哪里?(→ 设计要点,简要说明与保护范围的核心)
4. 有哪些视图素材?照片还是线条图?齐不齐(主/后/左/右/俯/仰 + 立体图)?(→ 视图清单;素材由发明人提供,AI 不代画)
5. 有几款相似设计要一起申请?(→ 相似设计:同一产品多项相似外观设计可作为一件申请,**不超过10项**(细则第40条),指定一项为基本设计)
6. 要不要**请求保护色彩**?(→ 色彩声明;请求后色彩成为保护范围限定,拿不准通常不请求)
7. 是否已公开(售卖/展出/发布/泄露)?(→ 专利法第24条宽限期判断,同发明)

## 类别与洛迦诺分类(阶段2 类型判断后提示)

- 洛迦诺分类(国际外观设计分类)用于**分类与检索**,不是保护范围的边界;类别以产品名称与用途为准。
- 写明产品所属类别的,应使用国务院专利行政部门公布的外观设计产品分类表(细则第53条)。
- 给出大类/小类方向性提示即可,精确分类号查《国际外观设计分类表》官方文本,不凭记忆编号。
- 类别填错 = 补正/审查风险,自检阶段核对(patent-compliance 外观项)。

## 简要说明(阶段3 生成 简要说明.md)

按细则第31条要求包含:
- 产品名称(与请求书、视图一致);
- 用途(写明有助于确定产品类别的用途;零部件还写明所应用的产品);
- 设计要点(与现有设计相区别的形状、图案及其结合,或色彩与形状、图案的结合,或部位),并**指定一幅最能表明设计要点的图片或照片**;
- 省略视图声明(如"左视图与右视图对称,省略左视图");
- 请求保护色彩声明(若请求;请求保护色彩应提交彩色图片或照片,细则第30条)。

**禁止**:商业性宣传用语、说明产品的性能(细则第31条第4款)。

## 相似设计与成套

- **相似设计**:同一产品多项相似外观设计可作为一件申请,不超过 10 项,指定一项为基本设计(细则第40条);判断"相似"由发明人说了算,AI 提示规则、不自作主张合并。
- **成套产品**:同一大类、习惯上同时出售或使用、且各产品具有相同设计构思(细则第40条)。
- 多项外观设计同案申请时,各项应顺序编号并标注在每幅图片或照片名称前(如"设计1主视图""套件2主视图")。

## 视图(素材由发明人提供,AI 只整理清单与合规核对)

- **视图种类按设计要点涉及的面数决定**(审查指南 第一部分第三章 4.2):设计要点涉及六个面 → 提交六面正投影视图;只涉及一个或几个面 → 提交所涉及面的正投影视图(其他面可提交立体图)。
- 平面产品:设计要点涉及一面可仅提交该面视图;涉及两面应提交两面视图。
- 省略视图:对称/相同面、使用时不轻易看到或看不到的面可省略,但必须在简要说明中写明原因(如"左视图与右视图对称,省略左视图")。
- 六面视图名称:主视图/后视图/左视图/右视图/俯视图/仰视图,标注在相应视图正下方(指南 4.2.1);主视图对应使用时通常朝向消费者的面或最大程度反映整体设计的面。
- 照片或线条图;实务常用黑白/灰度(请求保护色彩才保留彩色,并提交彩色图片或照片)。
- 各视图按正投影规则、比例一致,能清楚显示要求保护的产品外观(专利法第27条第2款;照片拍摄/图片绘制细节见指南 4.2.2/4.2.3)。
- 视图命名与简要说明的设计要点一一对应;详见 patent-drawings 的「外观设计附图」节。

## 保护范围与修改(给发明人讲清楚)

- 保护范围以表示在图片或照片中的该产品的外观设计为准,简要说明可用于解释(专利法第64条第2款)——视图本身决定保护范围,视图要慎重。
- 修改不得超出原图片或者照片表示的范围(专利法第33条第2款);外观设计可自申请日起 2 个月内主动修改(细则第57条第2款),图片或照片修改按替换页提交(细则第58条第2款)。
- 局部外观设计(可选提示):只改产品某一部分的,可申请局部外观设计,提交整体产品视图并用虚线与实线表明保护部分(细则第30条)。

## 边界

- 线稿工具(自动描边/矢量化)不随包提供:零脚本决策(ADR-0005),素材原样由发明人提供。
- 外观设计没有说明书/权利要求书/摘要,patent-claims / patent-specification 不参与外观分支。
