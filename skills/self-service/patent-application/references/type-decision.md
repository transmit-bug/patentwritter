# 申请类型判断决策树

规则依据:patent-standards 核实锚点(专利法 第2条/第9条/第22条/第23条/第26条/第27条/第42条;细则 第20条/第43条/第46条/第47条)。

## 决策树

```
技术方案是 方法/算法/工艺/配方 为主?
├─ 是 → 只能 发明
└─ 否(产品/装置/结构/系统)→ 判断改进点性质:
    ├─ 改进点在 外观(形状/图案/色彩,美感为主,不涉及功能结构)→ 外观设计
    │   (同一形状既美观又有功能效果:外观与实用新型/发明可并行考虑,分别申请)
    ├─ 改进点在 形状/构造/连接/布局 → 问:要不要方法也能保护?
    │   ├─ 要 → 一案两请(同日申请发明+实用新型)
    │   └─ 不要 → 问:想快还是想稳?
    │       ├─ 快(6-12月授权)→ 实用新型
    │       └─ 稳(20年保护/实审)→ 发明
    └─ 改进点含 材料配方/方法步骤 → 只能 发明(实用新型保护不到方法)
```

> 外观设计的边界:保护的是产品外观本身(美感),不是功能结构。发明人描述"造型/图案好看、防仿外观" → 外观设计;描述"结构改进解决了什么技术问题" → 发明/实用新型。拿不准时先问清楚改进点性质再定。

## 各类结论的规则依据(给用户讲清楚为什么)

| 判断 | 依据 |
|---|---|
| 实用新型只保护产品 | 专利法第2条第3款:实用新型=产品的形状、构造或其结合的新技术方案 |
| 外观设计保护外观本身 | 专利法第2条第4款:外观设计=对产品的整体或者局部的形状、图案或其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计 |
| 外观设计授权条件 | 专利法第23条:不属于现有设计;与现有设计或其组合相比有明显区别;不与他人在先合法权利冲突 |
| 外观设计申请文件 | 专利法第27条:请求书 + 图片或者照片 + 简要说明;图片或照片应清楚显示要求保护的产品外观设计 |
| 方法只能申请发明 | 专利法第2条第2款:发明=产品、方法或其改进 |
| 实用新型创造性标准低、授权快 | 专利法第22条第3款(实质性特点和进步 vs 突出的实质性特点和显著进步);只做初步审查(细则第43条起) |
| 保护期:发明20年/实用新型10年/外观15年 | 专利法第42条 |
| 实用新型必须附图 | 细则第20条/第43条 |
| 一案两请 | 专利法第9条:同日对同样的发明创造既申请实用新型又申请发明,先获实用新型、声明放弃后可获发明;细则第47条:申请时应分别说明 |

## 给发明人的话术要点

- **实用新型适合**:产品结构改进、想快速拿到保护、担心成本。**提醒**:实用新型创造性审查尺度较低,但拿到后维权同样有效。
- **发明适合**:有方法/算法、想要20年保护、可能涉及重大商业价值。
- **一案两请适合**:产品改进但方法也很重要,想先快后稳——同日递交两份,实用新型先授权先维权,发明实审通过后放弃实用新型。注意细则第47条:申请时就要分别说明。
- **外观设计适合**:产品的外观(造型/图案/色彩)本身是卖点,主要防别人仿外观。提醒:外观保护的是美感外观,不保护功能结构;功能改进请走发明/实用新型。保护期 15 年(专利法第42条)。
- **外观 + 实用新型可并行评估**:一个产品可能既有功能结构改进、又有外观改进,可分别申请(如结构创新申请实用新型、造型创新申请外观)。
- **先问一句**:是否可能出海?出海主要看发明(实用新型在多数国家没有对应制度),可提示但不展开。

```
判断依据:专利法第X条 / 细则第X条 …
给用户的说明:一段大白话,解释为什么是这个类型
```

外观设计追加(参考 `design-points.md`):

```
类别:产品名称 + 洛迦诺分类提示
设计要点:…

```
