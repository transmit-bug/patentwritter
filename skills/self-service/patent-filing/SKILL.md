# 递交与补正指引

输入:已完成的申请文件包 + 申请类型。本技能是向导:给出分步动作,**标注 👤 的步骤只有申请人本人能办**(注册/缴费/签字类,涉及身份与资金)。

## 递交前

1. 👤 确认申请人(个人/单位)与发明人名单,信息与身份证件一致。
2. 检查申请文件包齐全(发明/实用新型:申请信息.md / 权利要求书.md / 说明书.md / 摘要.md / 附图;外观设计:简要说明.md + 图片或照片)。
3. 👤 准备电子申请环境:访问 专利业务办理系统(cponline.cnipa.gov.cn),注册账号并申请**数字证书**(首次办理需实名认证,几天内生效)。

## 递交(电子申请)

1. 👤 登录系统,新建申请 → 选择 发明/实用新型/外观设计。
2. 👤 按系统表单填写:名称(与说明书一致)、申请人、发明人、联系人、费减信息。
3. 👤 上传权利要求书/说明书/摘要/附图文件,指定**摘要附图**(系统会提示;外观设计则上传图片/照片并指定最能表明设计要点的图片)。
4. 👤 提交 → 系统生成申请号 → **当日或次日**缴申请费。
   - 费用(以系统显示为准,此处为常年标准):发明申请费 900 元 + 公布印刷费 50 元;实用新型 500 元;外观设计 500 元。
   - 👤 费减备案:符合条件(个人/小微企业,标准以当年官方费减办法为准)可先备案,减缴比例以备案结果为准;逾期缴费 = 视为撤回,务必在缴费期限内完成。

## 递交后流程(给用户讲清楚,管理预期)

- **实用新型**:受理 → 初步审查(形式+明显缺陷)→ 授权。典型周期数月。
- **外观设计**:受理 → 初步审查(形式+明显缺陷)→ 授权。典型周期数月(同实用新型)。
- **发明**:受理 → 初步审查 → 公布(满18个月,可请求提前)→ 实审(需在申请日起**3年内**提出实质审查请求并缴费,逾期视为撤回)→ 授权。典型周期2-3年。
- 授权后:办理登记手续、缴年费,领取专利证书。

## 外观设计电子申请要点

- 申请文件 = 请求书 + 图片或者照片 + 简要说明(专利法第27条;**无**权利要求书/说明书/摘要)。
- 图片/照片格式与大小:以 专利业务办理系统 上传提示为准(2023 版细则与审查指南**已删除**旧版"图片不小于3cm×3cm、不大于15cm×22cm"之类的尺寸数值要求;要求是能清楚显示产品外观设计,专利法第27条第2款)。
- 视图:按设计要点涉及的面数提交正投影视图(涉及六面才需六面视图,见 patent-drawings 外观节),黑白/灰度实务,请求保护色彩才保留彩色并提交彩色图片或照片。
- 系统内指定一幅最能表明设计要点的图片。

## 补正通知书处理协议

收到"补正通知书"(初步审查阶段的形式缺陷,发明/实用新型/外观设计都可能有):

1. **先对照**:把补正事项逐条抄下来,和原申请文件核对(常见补正事项见下表)。
2. **修改原则**:能删不改——**修改不得超出原说明书和权利要求书记载的范围**(专利法第33条)。新增内容 = 超范围 = 死路。拿不准的特征,宁可删掉也不要"改进"它。
3. 👤 在通知书指定期限内(一般为2个月,以通知书为准)通过系统提交补正文件,逾期视为撤回。
4. 修改涉及说明书/权利要求替换页的,按系统要求提交替换页(细则第58条)。

### 常见补正事项对照表

| 补正事项 | 通常原因 | 处理 |
|---|---|---|
| 名称不一致 | 请求书/说明书/权利要求 名称没对齐 | 统一为同一名称 |
| 附图标记问题 | 文字与附图标记不一致/未按"图1,图2"编号 | 对齐标记(patent-compliance 检查4) |
| 缺少摘要附图/未指定 | 有附图但没指定摘要附图 | 指定最能说明技术特征的一幅 |
| 摘要含商业宣传语 | "首创""领先"等 | 删除 |
| 权利要求格式 | 多项从权引用违规/附图标记作限定 | 按细则第25条/第22条修正 |
| 缺文件 | 摘要/附图遗漏 | 补交(注意:补交附图可能影响申请日,见细则第46条) |
| 外观:类别/产品名称不符 | 请求书与简要说明/图片不一致 | 统一产品名称,核对洛迦诺分类 |
| 外观:视图不足或省略未声明 | 视图与设计要点涉及的面数不符、省略视图未在简要说明声明 | 补视图或补省略声明 |
| 外观:简要说明缺项 | 缺用途/设计要点/指定图 | 补全简要说明 |
| 外观:色彩声明缺失 | 请求保护色彩但未在简要说明声明 | 在简要说明补色彩声明 |

## 边界

- 实审阶段的**审查意见通知书(OA)答复**不在本技能范围——那是专业代理人方向(仓库 `professional/` 组)。
- 所有金额、期限、流程以 专利业务办理系统 与通知书实际内容为准,本技能只给结构,不给数字承诺。
